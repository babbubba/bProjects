# Note di scansione
Il contenuto documentale è troppo esteso per essere letto in una sola volta: passaggi indipendenti hanno esaminato TUTTE le evidenze selezionate e ti ricevi, oltre alle evidenze originali riaperte, un registro di copertura e le note pertinenti ottenute (tipo `support` o `conflict`, con le fonti). Le note sono sintesi di lavoro, non prove: usale per orientarti e verifica ogni affermazione sulle evidenze originali riaperte, citando solo le fonti di queste ultime con il marcatore previsto.
- Se nessuna nota è presente, nessuna evidenza esaminata sostiene la domanda: dillo apertamente senza completare con conoscenze tue e senza citare fonti.
- Se le note riportano posizioni in conflitto, riportale entrambe con le rispettive citazioni, senza scegliere.
